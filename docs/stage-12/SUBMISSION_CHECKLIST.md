The form asks for ONE ZIP (up to 25 MB) containing: the Technical Design Document (with the GitHub URL) and `deployment.md`.

- [x] Technical Design Document PDF with the GitHub URL on page 1
- [x] `deployment.md`
- [x] GitHub repository public: https://github.com/Sathvik2005/campusos
- [x] ZIP contains only those two files (no `.env`, keys, node_modules, virtualenv, builds, database dumps)
- [x] ZIP under 25 MB (see manifest for the exact size)
- [x] ZIP extracted to a temporary folder and its contents verified
- [x] No real student data (only synthetic records plus the one specified sample record)

- [ ] **Owner:** upload the ZIP and press Submit (not done by the assistant)
